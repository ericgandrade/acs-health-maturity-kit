# Report Quality Checklist

Run before any report leaves the assessment team.

## Accuracy
- [ ] Every score matches the scoring tool output.
- [ ] Every finding cites at least one question ID.
- [ ] HHS goal references use the exact goal names from the CPG Crosswalk.
- [ ] Licensing statements cite the License-Security Map and say "verify against current Microsoft documentation and your agreement".
- [ ] No invented numbers: costs, savings, percentages and dates come from the user or from a cited source.
- [ ] The proposed HIPAA Security Rule update is described as proposed unless an official final rule is cited.

## Privacy and safety
- [ ] No PHI anywhere in the documents.
- [ ] No passwords, keys, IP addresses, firewall rules or vulnerability details that would help an attacker.

## Usefulness
- [ ] The executive summary fits on one page and states the three most important actions.
- [ ] Every roadmap action has an owner role, a horizon, the question IDs it closes and a measurable indicator.
- [ ] Actions that use capabilities the organization already owns are identified as quick wins.
- [ ] Open questions and missing evidence are listed with an owner.

## Positioning
- [ ] The report states that it is a self-assessment aid, not legal, licensing or compliance advice, and does not certify HIPAA compliance.
- [ ] Suggested dispositions and priorities are presented as recommendations for the accountable owners to decide.
