# Evidence Checklist

Evidence confirms an answer of 3 or 4. It can be shown on screen; do not copy PHI, secrets or network details into the workbook.

## License Optimization
- [ ] SAM owner, licensing policy and RACI (LO-01, LO-02)
- [ ] Renewal calendar and last renewal review (LO-03)
- [ ] Entitlement register and last reconciliation (LO-05, LO-06, LO-07)
- [ ] Discovery and usage reports (LO-09, LO-10)
- [ ] Offboarding procedure and HR-to-directory reconciliation (LO-11)
- [ ] MFA, endpoint, email and data protection coverage reports (LO-13 to LO-16)
- [ ] Cloud tagging policy, cost allocation, commitment coverage, budgets (LO-17 to LO-20)
- [ ] Program eligibility, agreement analysis, effective license position (LO-21 to LO-24)

## App Modernization
- [ ] Application inventory with owners and criticality (AM-01, AM-03, AM-04)
- [ ] Interface catalog or dependency map (AM-02)
- [ ] Platform support status and remediation plans (AM-05, AM-06, AM-07)
- [ ] Segmentation of non-upgradable systems (AM-08)
- [ ] Dispositions, roadmap, capability map, cost per application (AM-09 to AM-12)
- [ ] Change records, test reports, pipeline security settings, AI usage policy (AM-13 to AM-16)
- [ ] Backup configuration, restoration and DR test reports, downtime procedures, monitoring (AM-17 to AM-20)
- [ ] Cloud foundation, business associate agreements, data classification and retention policy (AM-21 to AM-24)

## Zero Trust
- [ ] MFA coverage, shared account report, privileged account inventory, offboarding records (ZT-01 to ZT-04)
- [ ] Asset inventory coverage, vulnerability reports, device compliance and baselines (ZT-05 to ZT-08)
- [ ] Segmentation design, remote access architecture, encryption in transit (ZT-09 to ZT-11)
- [ ] Email authentication records, access policies, penetration test reports, vendor clauses (ZT-12 to ZT-15)
- [ ] Encryption at rest, data map, DLP policies, backup isolation (ZT-16 to ZT-19)
- [ ] Log sources, detection and response arrangement, PHI access reviews (ZT-20 to ZT-22)
- [ ] Risk analysis and plan, incident response exercises, training results, vendor assessments, remediation tracker, Zero Trust strategy (ZT-23 to ZT-28)
